## Novità

- **Confronto tra versioni.** Se la cartella è un repository git, **⋯ › Versioni e confronto…** mostra il documento con il testo **aggiunto in verde** e quello **tolto in rosso**, parola per parola, anche nelle tabelle e negli elenchi. **↑ ↓** saltano da una modifica all'altra e **Solo le modifiche** nasconde le parti uguali. Si confronta ogni versione con quella da cui deriva, con il testo di adesso o con qualsiasi altra versione (**Maiusc + clic** nell'elenco).
- **Chi ha cambiato questa riga.** La vista **Autori** mostra per ogni riga chi l'ha scritta o cambiata per ultimo, quando e con quale messaggio; un clic mostra quella modifica. **⋯ › Chi ha modificato questo punto…** la apre sulla riga del cursore.
- **Storico a nodi.** Le versioni sono una linea del tempo con i rami, le unioni e le etichette; **Tutta la cartella** (anche da **Cartelle e file › Storico git della cartella…**) mostra tutti i commit del repository e, per ciascuno, i file cambiati con il loro confronto.
- **Novità delle versioni.** Le note di ogni versione sono dentro Itaca: clic sulla versione accanto al nome o **Impostazioni › Aggiornamenti › Novità delle versioni**. Dopo un aggiornamento un avviso le propone.
- **Natale con la slitta.** Scegliendo il tema Natale parte da sola la slitta di Babbo Natale; lasciando il tema torna l'animazione di prima.
